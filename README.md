# gerency-jokes-api

Api made to manage the best jokes of the world!

This is a Node.js project built using **TypeScript**, **Solid architecture**, **unit tests**, **design patterns** (Factory and In-Memory), **Docker**, and **Prisma ORM**.

---

## 🧱 Stack

* **Node.js** `v20.14.0`
* **TypeScript**
* **Fastify**
* **Prisma**
* **Docker / Docker Compose**
* **Vitest** (for unit tests)
* **SOLID principles**
* **Design Patterns** (Factory, In-Memory Repository)
* **Python** (for the Machine Learning service)
* **Uvicorn / FastAPI** (ML API)

---

## 🚀 How to Run the Project

### 1. Clone the repository and install dependencies

```bash
git clone <your-repo-url>
cd <your-project-folder>
npm install
```

### 2. Setup environment variables

Rename the `.env-example` file to `.env` and fill in the required environment variables.

```bash
cp .env-example .env
```

> Example variables: `DATABASE_URL`, `PORT`, etc.

---

### 3. Start containers using Docker Compose

```bash
docker-compose up -d
```

This will start your application and its dependencies.

---

### 4. Run database migrations (Prisma)

```bash
npx prisma migrate dev
```

---

### 5. Start the development server

```bash
npm run dev
```

Your API should now be running at `http://localhost:3000` (or the port defined in your `.env`).

## 🤖 Machine Learning Service

The repository contains a Machine Learning module under the `machine_learning/` directory, responsible for classifying jokes into predefined categories.

### 📂 Directory Structure (machine_learning)

```
machine_learning/
├── api.py              # ML API (FastAPI)
├── encoder.pkl         # Automatically generated after training
├── label_encoder.pkl   # Automatically generated after training
├── joke_classifier.pkl # Model generated by training.py
├── jokes.json          # Dataset used for ML training
├── training.py         # Script to train the classifier
└── validation.py       # Script to validate predictions
```

### 🧠 1. Train the Machine Learning model

Requires **Python 3** installed.

From inside the `machine_learning` directory:

```bash
python training.py
```

This will generate the following files:

* `joke_classifier.pkl`
* `encoder.pkl`
* `label_encoder.pkl`

---

### ✅ 2. Validate the generated model

```bash
python validation.py
```

---

### 🌐 3. Run the ML API

#### Option A — from inside `machine_learning/` directory

```bash
uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

The API will be available at:

```
http://127.0.0.1:8000
```

#### Option B — from root of the repository

The project provides an NPM script to run the ML API:

```bash
npm run ml-api
```

### 📡 ML API Routes

#### **POST /predict**

Predicts the category of a joke based on the trained classifier.

**Python (FastAPI) route implementation:**

```python
@app.post("/predict")
def predict_joke_category(request: JokeRequest):
    vector = encoder.encode([request.joke])
    predicted_index = clf.predict(vector)[0]
    category = label_encoder.inverse_transform([predicted_index])[0]
    return {"category": category}
```

Example request:

```json
{
  "joke": "Por que o programador foi ao médico? Porque tinha um bug!"
}
```

Example response:

```json
{
  "category": "Nerd"
}
```

## 🗂 API Routes (Main Node.js API)

### 📁 Categories

| Method | Endpoint          | Description           |
| ------ | ----------------- | --------------------- |
| POST   | `/categories`     | Create a new category |
| GET    | `/categories`     | Get all categories    |
| GET    | `/categories/:id` | Get category by ID    |
| PUT    | `/categories/:id` | Update category by ID |
| DELETE | `/categories/:id` | Delete category by ID |

### 🃏 Jokes

| Method | Endpoint     | Description       |
| ------ | ------------ | ----------------- |
| POST   | `/jokes`     | Create a new joke |
| GET    | `/jokes`     | Get all jokes     |
| GET    | `/jokes/:id` | Get joke by ID    |
| DELETE | `/jokes/:id` | Delete joke by ID |
